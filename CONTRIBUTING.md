# Contributing

The [contribution guide](docs/dev/contributing.md) covers change scope, tests, and
release-note fragments. See the [development guide](docs/dev/dev_environment.md) for
the existing Docker-based workflow and [architecture](docs/dev/arch_decision.md) for
the main components.

Use synthetic examples and fixtures. Do not submit credentials, real environment
files, database dumps, internal addresses, or unredacted operational logs. Preserve
existing migrations and intentional script execution logging.

Describe the behavior changed, tests performed, and any verification limitations.
See [security and data handling](docs/admin/security.md) before sharing diagnostics.
