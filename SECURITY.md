# Security

Do not disclose vulnerabilities or sensitive diagnostics in public issues. The
public project's private reporting route has not yet been designated. Until it is
available, use your deployment's internal security process. Establishing an actual
private contact is a prerequisite for public release.

See [security and data handling](docs/admin/security.md) for the trust boundary,
intentional execution logging, credential handling, and guidance for sharing reports.

Supported dependency ranges are documented in the
[compatibility guide](docs/admin/compatibility_matrix.md). No security-maintenance
commitment for historical releases is implied.
